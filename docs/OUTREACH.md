# Recrutamento — coorte inicial

## Objetivo

Recrutar três desenvolvedores iniciantes para validar a jornada completa antes de ampliar o piloto para dez participantes.

## Perfil

- possui ao menos um repositório público com README incompleto;
- consegue dedicar entre 30 e 60 minutos à melhoria;
- aceita registrar início, contribuição e feedback publicamente;
- entende que ALPHA é testnet, sem valor financeiro e sem promessa de emprego.

## Convite curto

> Estou testando o ALPHA Builders, um ciclo gratuito de revisão de README para desenvolvedores iniciantes. Você escolhe um projeto público, faz uma melhoria pequena e recebe feedback estruturado em até 48 horas. O piloto usa GitHub e uma carteira de testnet apenas para identidade verificável; não envolve pagamento ou transação. Interesse em participar desta primeira coorte?

## Canais

1. Contato direto com três pessoas que já tenham projeto público.
2. Uma comunidade de estudos ou bootcamp, sem publicação massiva.
3. Rede profissional do mantenedor, com convite individual e transparente.

## Decisão da coorte

Concluir a coorte quando os três participantes terminarem ou após sete dias sem progresso. Registrar fricções, tempo de revisão e feedback antes de convidar os próximos sete.
